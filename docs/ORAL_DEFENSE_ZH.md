# 项目中文讲解：你需要能解释的内容

这份文件帮助你理解项目，不替代英文提交报告。署名：Haodong Huang，个人项目。

项目现名 **Who Wrote It?**。下面第 8—13 节保留的是初版实验，优化方法和新版结果见 [第二轮优化说明](ITERATION_NOTES_ZH.md) 及英文报告的 Optimized results 表。

## 1. 我们到底训练了什么？

我们训练的是分类器，不是 GPT 或 Llama 本身。输入 X 是问题、回答或二者组合；真实标签 y 是 Falcon、GPT、Llama 三选一。CNN 和 LSTM 都是我们本地训练的小网络。

## 2. 数据从哪里来？

来自公开的原始 UltraFeedback。它记录了问题、模型名称和回答。我们只保留三个家族都回答过的问题，每个问题每个家族选一条，所以最终是 1,418 个问题 × 3 = 4,254 条回答。没有利用质量评分挑“更容易分对”的答案。

## 3. 为什么同一个问题要有三个家族的回答？

如果 GPT 总回答数学，而 Falcon 总回答诗歌，分类器可能只学到题目差异。同题配对让三类面对完全一样的问题集合，更方便判断回答本身提供了什么信息。

## 4. 为什么只看问题一定是 33.3%？

同一道问题会出现三次，文字相同，但标签分别是三个家族。确定性的模型看到相同文字，会给相同预测。因此每组三条必然只对一条。这个实验是刻意设计的对照，并不代表自然场景中的问题永远没有预测作用。

## 5. 为什么不能把所有行随便打乱后切分？

那会让同一道题的回答分别进入训练和测试。我们按问题分组，还把检测到的近重复问题放在同组。训练、验证、测试分别有 992、213、213 个问题。预测词表只从训练集构建。

## 6. CNN 和 LSTM 怎么读文字？

先把文字切成 token，再查表变成 64 维可训练向量。CNN 用宽度 3、4、5 的窗口找局部模式，再通过 max pooling 汇总。LSTM 按顺序读取 token，通过门控制保留、更新和输出的信息；我们取最后一个真实 token 的隐藏状态来分类。

CNN 的思路对应 Chapter 4 的卷积与池化；LSTM 对应同章的循环网络部分。训练损失和 Adam 对应 Chapter 9。

## 7. 它怎么学习？为什么会停止？

用多分类交叉熵衡量预测与真实标签的差距，通过反向传播和 Adam 更新参数。每批 64 条，最多训练 8 轮。如果验证表现连续 3 轮没有改善，就提前停止。选验证 macro-F1 最高的模型，相同时选验证损失更低的。不能看测试成绩来决定调哪个参数。

## 8. 我们的主要结果是什么？

CNN 只看回答：平均准确率 77.52%；LSTM：64.01%。加上问题后分别降到 73.87% 和 59.21%。每项跑三个随机种子。我们不能因此宣称“CNN 永远胜过 LSTM”，只能说在这份数据、这个模型规模和训练设置下如此。

## 9. 为什么加问题反而更差？

这份同题配对数据中，问题本身不能区分类别。加进去可能增加无关变化，让小模型更难集中在回答特征上。不过“干扰”“容量不足”只是合理解释，我们没有用独立实验完全区分这些原因。组合输入为问题保留 96 token、回答保留 192 token，因此不是问题太长把回答挤没了。

## 10. Accuracy 和 macro-F1 有什么区别？

Accuracy 是整体预测对的比例。Macro-F1 是先分别计算三个类别的 F1，再等权平均。只猜一个类别也能在平衡数据上得到 1/3 accuracy，但 macro-F1 会很低，因此两者要一起看。

## 11. 我们怎样证明结果不是碰巧？

主实验跑了三个训练随机种子，报告均值和标准差。另用 2,000 次按重复问题组抽样的 bootstrap 计算区间。同组的三条回答一起抽，保留相关性。区间表达当前数据和拟合模型条件下的不确定性，不能替代更多数据、更多种子或其他划分。

## 12. 加分分析做了什么？

RQ4：只用长度、词汇多样性、标点等结构特征也能达到约 56.8%。去掉显式长度特征后几乎不变。去掉标点和换行后重训，LSTM 有改善，CNN 的变化证据不足。注意预处理也改变了 token 数量，不能把变化全归因于标点。

RQ3：训练时不看 Evol-Instruct 来源，测试时只看其 58 道测试题；与训练量相同、但包含混合来源的模型比较。两种模型仍超过随机水平，但相对对照的差异区间包含 0，所以不能宣称已经证明跨领域性能不下降。数据来源只是领域变化的近似，不是真正人工标注的任务分类。

## 13. 为什么还放逻辑回归和打乱标签？

TF-IDF + 逻辑回归达到约 77.3%，说明简单方法已经很有竞争力。打乱训练标签后，CNN 和 LSTM 分别只有约 26.4% 和 29.6%。这两次是低于随机水平，不是恰好随机；说明错误监督没有保留原来的识别能力，但一次打乱不能证明所有漏洞都不存在。

## 14. 最重要的局限是什么？

旧版本模型、有限来源、同题筛选带来的偏差、不同系统提示和生成原则、截断回答、有限训练预算。我们也只使用一个数据划分；加分神经网络实验只有一个种子。模型不适合用来断言任何人的文章一定来自某个 AI。
