# Reproducibility notes

- Original experiment date: October 10, 2026.
- Python 3.12.13; dependency versions are in requirements-lock.txt.
- Fixed data-construction seed: 448. Validation split seed: 449.
- Primary initialization seeds: 448, 449, 450. Auxiliary seed: 448.
- Per-prompt selection uses a SHA-256-derived seed plus 448.
- Source checksums are embedded in download_data.py as well as recorded in data_provenance.json.
- The split manifest excludes response text but records original generator version and source for audit.
- A resumed run requires its metrics, checkpoint, and predictions; missing local-only assets cause retraining.
- MPS and CPU can differ numerically. The original MPS run is the reported snapshot, not a guarantee of identical cross-platform values.
- The PDF is generated by ReportLab; pdftoppm is used only for visual QA and is not necessary to rebuild the PDF.
- The editable Markdown report is generated from the same report builder. For durable report changes, update src/build_report.py before rebuilding.
- No raw text, source course PDFs, or private credentials belong in the submission repository. Initial and optimized project-trained demonstration checkpoints are included in models/; all non-text predictions are included for metric audit.

## Optimization stage

See docs/iteration_plan.json for the bounded candidate list and docs/iteration_selection.json for the frozen validation-based choice. src/iterate.py exposes separate search, confirm, and evaluate phases. Training/validation snapshots and non-text predictions are published under results/v2/. All 32 fit records remain available; only 18 selected conditions are evaluated on the existing test set. Run src/verify_v2.py to recompute validation scores, selections, and test metrics, then replay the optimized checkpoints.
