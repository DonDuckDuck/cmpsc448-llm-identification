# 第二轮优化：Whose Slop Is It?

“Who Wrote It?”来自老师的作业原题。我们把自己的项目标题改为更有辨识度的 **Whose Slop Is It?**，副标题仍明确说明是 LLM 家族识别研究。题名是趣味表达，实验标签识别的是来源，不是回答质量。

## 为什么改 LSTM？

初版使用一个 LSTM 的最后隐藏状态表示整个回答。这个状态包含此前信息，并不是只看最后一个词；但它必须把整个序列压缩成一个小向量。

优化版比较了另一种汇总方式：对每个真实 token 的隐藏状态做平均池化和最大池化，再拼接起来。这样，出现在回答前部或中部的强特征也可以进入分类层。PAD 位置不参与汇总。

双向 LSTM 同时从前向后和从后向前读文本。我们只反转真实 token 的前缀，不把补齐用的 PAD 当作真实上下文。实现与 PyTorch 的 packed 双向 LSTM 做了数值对照，也验证了改变 batch 内其他样本长度不会改变同一文本的预测。

## 怎样选更好的模型？

1. 先固定 12 个候选：4 个 CNN、8 个 LSTM。比较结构、token 上限、维度、学习率及文本预处理。
2. 第一轮全部使用种子 448，只看训练与验证集。
3. 每类架构验证表现最好的两个候选，再跑种子 449 和 450。
4. 按三个种子的平均验证 macro-F1 选出 CNN 和 LSTM 各一个方案，将选择写入冻结记录。
5. 用选定方案补齐三种输入、三个种子的实验，全部训练完成后再评价测试集。

训练上限为 24 轮，验证表现连续 5 轮没有提升就停止。CNN 和 LSTM 的最优候选不一定需要最大维度或双向结构，实际选择由验证结果决定。

## 需要怎么解释结论？

以英文报告中“Optimized results”表为准。不要拿单次最高测试成绩代表全部结果，要说三个种子的均值和波动。

我们已经见过初版测试结果，第二轮属于同一个划分上的后续研究，不能把它说成完全未接触的新测试。新配置只按验证集选择，但初版结果影响了研究方向，因此仍需要独立新数据检验泛化。

初版的跨来源、格式消融和打乱标签实验保留为初版证据；这些结论不能直接套到优化版模型。原始实验没有被隐藏或删掉。

## 第二轮实际结果

| 模型 | 初版只看回答 | 优化版只看回答 | 提升 |
|---|---:|---:|---:|
| CNN | 77.52% | 80.91% | 3.39 个百分点 |
| LSTM | 64.01% | 77.00% | 12.99 个百分点 |

以上均为三个随机种子的平均值。优化后加入问题的准确率分别为 CNN 79.08%、LSTM 75.64%；相对只看回答的差异区间都包含 0，因此不能再把初版“下降较明确”的结论直接照搬过来。

最终选中的是单向池化 LSTM，不是双向版本。双向和更大的模型确实被测试了，但验证结果没有让它们胜出。
