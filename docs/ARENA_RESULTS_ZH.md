# Arena 实验结果速览

作者：Haodong Huang。主报告维持老师原题。以下数字由实际测试结果生成。

数据：9,643 条回答；训练/验证/测试 = 6,735/1,442/1,466；四个固定版本 Claude Sonnet 4、GPT-4.1、Grok 3、DeepSeek V3。

| 模型 | 输入 | 准确率 | Macro-F1 | Balanced accuracy |
|---|---|---:|---:|---:|
| CNN | input | 26.94% | 26.31% | 26.69% |
| CNN | output | 86.79% | 86.51% | 86.49% |
| CNN | combined | 86.54% | 86.18% | 86.22% |
| LSTM | input | 25.15% | 24.06% | 25.25% |
| LSTM | output | 83.04% | 82.52% | 82.63% |
| LSTM | combined | 81.20% | 80.79% | 80.95% |

CNN 加入问题后的 macro-F1 差值：-0.33 个百分点；95% 组重采样区间 [-1.44, +0.78]。

LSTM 加入问题后的 macro-F1 差值：-1.73 个百分点；95% 组重采样区间 [-2.89, -0.54]。

以上为三个种子的均值。跨领域、格式消融与打乱标签为单种子诊断。新旧数据集的标签数、版本和划分不同，不要把旧三分类与新四分类的分数直接解释为提升。完整解释与局限见英文报告及 ARENA_PROTOCOL_ZH.md。

## 补充实验（主实验评估之后）

计划先写入 docs/arena_followup_plan.json，再运行；没有用测试标签选择任何设置。测试集此前已用过，因此属于后续分析，不是第二次确认。

- 学习曲线（固定划分）：训练数据从 841 增加到 6,735 条，CNN macro-F1 75.59% → 86.51%，LSTM 65.99% → 82.52%。
- 去掉长度信息（每条回答都截成正好 128 token）：CNN 81.86%，LSTM 82.06%。
- 同一问题、两个作者的 76 对：CNN 正确分配 99.12%；只看问题必然是 50%。
- 指纹位置：开头窗口最强，中间最弱；CNN 依赖开场白与 Markdown 习惯。
- 等权融合 CNN+LSTM+字符 TF-IDF：macro-F1 89.48%。
